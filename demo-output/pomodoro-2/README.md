# Pomodoro Timer with Stats

A responsive, offline Pomodoro timer built with plain HTML, CSS, and JavaScript.

## Use

Open `index.html` in a browser. Start begins a work or break session, Pause retains the current time, and Reset returns to a 25:00 work session with zero completed tomatoes.

The timer alternates between 25-minute work sessions and 5-minute breaks. Completing a work session increases the tomato count. All state is in memory and resets on reload.

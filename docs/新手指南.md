# 新手指南：从一句话到比赛材料

不需要懂 AI，也不需要会写代码。按下面做，大约 10 分钟。

## 1. 准备（只做一次）

1. **安装 Python 3.10 或更新版本**：<https://www.python.org/downloads/>
   安装时勾选 **Add python.exe to PATH**。
2. **安装浏览器**：电脑上有 Chrome 或 Edge 就行（Windows 自带 Edge）。
3. **准备一个 AI**（二选一）：
   - **便宜，推荐**：去 <https://platform.deepseek.com> 注册、充值几块钱、创建 API key，
     然后在命令行里设置（Windows PowerShell）：
     ```powershell
     setx DEEPSEEK_API_KEY "你的key"
     ```
     设置完**关掉命令行窗口再重新打开**。做一个网页大约花几分钱。
   - **已经有 Claude 订阅**：安装 Claude Code 并登录（`claude auth login`），不需要任何 key。

## 2. 开始

- **Windows**：双击项目里的 `start-windows.bat`。
- **其他系统**：在项目目录运行
  ```bash
  pip install -e .
  rocto
  ```

它会用中文问你“想做一个什么样的网页”。输入一句话，比如：

> 做一个大学生课程表网页，可以添加课程、按星期查看，并高亮今天的课

然后等 1～3 分钟。它会自己规划、写代码、在浏览器里逐项测试，不合格就自己返工。

做完后它会问“要生成比赛提交材料吗？”，回答 **Y**。

## 3. 你会得到什么

在网页目录旁边会多一个 `xxx-kit` 文件夹：

| 文件 | 用途 |
| --- | --- |
| `作品说明书.md` / `作品说明书.html` | 比赛要交的说明文档。html 用浏览器打开后可以另存为 PDF |
| `截图/桌面版.png`、`截图/手机版.png` | 作品截图 |
| `源码.zip` | 源代码压缩包 |
| `测试报告.html` | 自动测试的证据：测了什么、结果如何 |
| `答辩准备.md` | 评委可能问的 5 个问题和参考回答 |
| `提交清单.txt` | 提交前逐项打勾 |

## 4. 提交前一定要做的三件事

1. **亲手用一遍**：打开 `源码/index.html`，把每个功能都点一遍。
2. **读懂它**：读《答辩准备.md》，每个问题都能用自己的话回答。评委会问，照念是过不了的。
3. **看比赛规则**：有的比赛允许用 AI、要求声明；有的不允许。说明书第八节已经写好了
   AI 使用声明。**如果规则不允许使用 AI，就不要提交。**

## 5. 常用命令

| 想做的事 | 命令 |
| --- | --- |
| 检查环境缺什么 | `rocto doctor` |
| 做一个网页 | `rocto build "一句话需求"` |
| 省钱模式（便宜的 AI 优先） | `rocto build "……" --mode cheap` |
| 在做好的网页上改东西 | `rocto refine "要改什么"` |
| 中途断了，接着做 | `rocto resume` |
| 打开报告 | `rocto open` |
| 生成比赛材料 | `rocto kit` |
| 生成比赛材料，完全不花钱 | `rocto kit --no-ai` |
| 看一共花了多少 | `rocto stats` |

## 6. 怎么让作品更容易获奖

工具能帮你把“做出来”这一步变快，但评委看的是**想法**和**你对作品的理解**：

- 需求越具体越好：写清楚给谁用、解决什么问题、有哪几个功能。
- 先做一个小而完整的版本，再用 `rocto refine` 一点点加功能，每次都会重新测试。
- 选一个你自己真的遇到过的问题来做，答辩时才有话说。
